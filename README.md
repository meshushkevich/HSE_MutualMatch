# **Mutual Match: будет ли взаимная симпатия?**

Годовой проект магистерской программы **«Искусственный интеллект»**  
Набор **26/27**, ML-трек

## **Описание проекта**

После короткой встречи участники speed dating заполняют анкету с оценками партнёра и решением, хотят ли увидеться снова. В проекте финальные решения и наиболее близкие к ним субъективные поля исключаются, а модель ретроспективно связывает взаимные оценки с итоговым match.

**Цель проекта** — разработать модель бинарной классификации и ретроспективный демонстрационный сервис, который по взаимным оценкам после короткой встречи оценивает вероятность зафиксированного в эксперименте match.

> ⚠️ **Важное ограничение.** Данные относятся к конкретному американскому эксперименту начала 2000-х. Одна встреча исходно может встречаться дважды с разных точек зрения. Оценки и решение собирались после встречи, поэтому модель не является ранним прогнозом. Поля финального решения и близкие к нему like / guess\_prob\_liked исключаются из основной модели. Система является только учебной демонстрацией и не измеряет совместимость людей.

## **Метрики качества**

| Метрика | Описание |
| ----- | ----- |
| **PR-AUC** | Основная метрика для несбалансированных классов |
| **F1-score** | Баланс precision и recall |
| **ROC-AUC** | Общая разделяющая способность модели |
| **Calibration error / Brier score** | Качество калибровки вероятностей |
| **Precision / Recall для класса match** | Детальный анализ по целевому классу |
